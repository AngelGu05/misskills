# misskills

Skills personales para Claude.

| Skill | Para qué sirve |
|---|---|
| [`escuela-ciencias`](escuela-ciencias/SKILL.md) | Convierte un tema de ciencias de la escuela (video de YouTube, PPT, apuntes, exámenes viejos) en una explicación fiel, apuntes corregidos y una app de estudio con animación interactiva, lectura completa, examen tipo profesora y práctica. Además la publica en claude.ai, GitHub y Vercel. |

## Cómo usarlas

- **Claude Code:** copia la carpeta de la skill a `~/.claude/skills/` (para todos tus proyectos) o a `.claude/skills/` dentro de un proyecto.
- **claude.ai:** comprime la carpeta de la skill en un `.zip` y súbela en *Settings → Capabilities → Skills*.

Después basta con pedirlo con naturalidad, por ejemplo: "explícame este video de mitosis y hazme una app para estudiar".
